FAQ

Questions before you use PlagiGuard?

A few quick answers for students, researchers and instructors.

Does PlagiGuard search the whole internet?

No. This project is browser-first and compares text available inside the application using tokenization, n-grams and Jaccard similarity. It does not call an internet plagiarism API.

Can students change the similarity rules?

No. N-gram size, threshold and minimum-word settings are instructor-only in the authenticated workspace.

Can instructors create the next assignment?

Yes. Instructors can create and publish assignments from the Assignments & Submissions workspace, where the new assignment then appears for students.

Can students see whether they were flagged?

Yes. Students see similarity, the highest match when available, and a clear Flagged, Not Flagged or Awaiting comparison status.

Where is my data stored in this build?

User accounts, settings, assignments and submissions are stored in the browser using localStorage, with the active login stored in sessionStorage.
