About the project

Why we built SimScore

SimScore is a semester project that turns a classic computer science idea — set similarity — into a tool a real instructor can use.

The purpose

Instructors collect dozens of written assignments every term. Copying between classmates is common, but catching it means reading every submission and remembering the wording of all the others at the same time.

SimScore removes that memory problem. It scores every possible pair of submissions and shows only the ones that deserve a human look. The tool never accuses anybody — it only points at pairs that are unusually similar, and the instructor makes the final decision.

Design rules we set for ourselves

  • No external plagiarism API. The similarity algorithm is written by hand so we actually understand every step.
  • No frameworks. Plain HTML, CSS and vanilla JavaScript only.
  • Privacy first. Assignment text stays in the browser's own storage and is never uploaded anywhere.
  • Separated code. UI files draw the screen, logic files do the maths. Neither one is allowed inside the other.

Who uses it

Two roles, two very different needs.

👤

The instructor

Adds the class submissions, runs the comparison and reviews the ranked list of suspicious pairs.

  • • Sees the full similarity matrix
  • • Sorts pairs from highest score down
  • • Opens any pair to compare the text
  • • Decides what counts as plagiarism
🎓

The student

Pastes an assignment into the submission form and gets an instant word-count check before the work is stored.

  • • Simple textarea, no file upload needed
  • • Live word counter with a minimum limit
  • • Clear confirmation after submitting
  • • Cannot see other students' scores

What SimScore is not

A high score is a signal for review, never a proof of cheating.

It does not search the internet.
Only the submissions you add are compared with each other.

It does not understand meaning.
Fully reworded work with the same idea will score low.

It does not judge.
Shared quotations or a common template can raise the score honestly.
